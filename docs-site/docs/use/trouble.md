## 準備と接続

| メッセージ | 対処 |
| --- | --- |
| 環境変数 COV_USER と COV_AUTH_KEY を設定してください | [準備の手順2](setup.md#2-認証情報の設定)のとおり設定します。Linux では、設定したターミナルから `copilot` を起動します |
| 認証できませんでした（HTTP 401） | `COV_USER` と `COV_AUTH_KEY` を確認します。Windows で保存し直したときは、新しいターミナルで `copilot` を起動し直します |
| 認証できませんでした（HTTP 403） | 認証情報が正しくても、ユーザーに「Access Web services」の権限がないと出ます。Coverity の管理者に確認します |
| Coverity に接続できませんでした | 設定の `coverity.url` とネットワークを確認します。プロキシは、OS の設定か、環境変数 `HTTPS_PROXY`・`NO_PROXY` が使われます。社内の証明書は、OS の証明書ストアから読まれます |
| Coverity Connect の応答ではありません | `coverity.url`（ポート番号を含む）を確認します。Coverity ではなく、ログインページやプロキシが応答しています |
| ストリーム … が見つかりません | `coverity.stream` を確認します |
| conditions に、Coverity にない値があります | `impacts` と `classification` の値を、Coverity での表記に合わせます |
| git または svn のリポジトリの最上位フォルダーで実行してください | リポジトリの最上位のフォルダーで `copilot` を起動し直します |
| 設定ファイルを訂正してください | 示されたキーを直します。`output_dir` には、リポジトリの外を指定します |

## 処置の途中

| メッセージ | 対処 |
| --- | --- |
| 条件に合う警告はありません | 設定の `conditions` を確認します。保留にした警告は、`classification` に `Pending` を加えるまで取得されません |
| CID … は、設定ファイルの条件で取得した警告（… 件）の中にありません | 条件を変えて「条件に合う警告を取得して」と入力してから、もう一度依頼します |
| エージェントが CID … を処置中です | エージェントの処置が終わってから、もう一度依頼します |
| …が失敗しました | 表示されたログを読みます。作業用コピーの準備、ビルド、解析のどれかが失敗しています |
| 作業用コピーがありません | 同じ依頼をもう一度入力すると、作業用コピーを作り直して続きから進みます |

## OK 後

| メッセージ | 対処 |
| --- | --- |
| Coverity への登録は行われていません | 許可しなかったか、エラーが出ました。「修正を取り込んで」と入力すると、登録をやり直します |
| push に失敗しました | 原因を取り除いてから「修正を取り込んで」と入力すると、もう一度 push します |
| ブランチ … がチェックアウトされています | 別のブランチに切り替えてから、「修正を取り込んで」と入力します |
| git を 2.32 以降に更新してから… | git を更新してから、「修正を取り込んで」と入力します |
| 取り込み先のコードに適用できませんでした | 先に取り込んだ修正と同じ箇所を変えています。その修正をマージ（svn ではコミット）してから、この CID をもう一度処置します |
| 作業コピーが最新でないときは、svn update を… | `svn update` を実行してから、「修正を取り込んで」と入力します |
| 一覧を表示した後に、結果または選択が変更されています | 何も処理されていません。表示し直された一覧を確認して、もう一度答えます |

## 画面

| メッセージ | 対処 |
| --- | --- |
| この URL では画面を表示できません | チャットで「画面を開いて」と入力し、新しく表示された URL を開きます |
| 結果フォルダーが新しくなっています | ページを読み込み直します |
