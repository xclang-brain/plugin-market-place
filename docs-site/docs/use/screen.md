# 画面で選ぶ

ブラウザーの画面で、処置の進捗と、CID ごとの修正コード・逸脱コメントを見ながら、どれを採用するかを選びます。チャットで処置した結果も、エージェントに任せた結果も表示できます。

## 開く

`copilot` で次の文を入力します。

```text title="チャットに入力"
画面を開いて
```

この PC のブラウザーで画面が開きます。開かないときは、チャットに表示された URL を開きます。

- エージェントの処置中に開くときは、別のターミナルで `copilot` を起動して入力します。進捗が数秒ごとに更新されます。
- Linux では、そのターミナルで先に[認証情報の3行](setup.md#2-認証情報を設定する)を実行します。OK の後に Coverity へ登録するのに必要です。

## 選ぶ

1. 一覧の CID（例：▸ 20001）を選ぶと、根拠、修正コードの差分、逸脱コメントが開きます。
2. 「修正を取り込む」「逸脱コメントを登録する」「保留にする」から選びます。選んだ内容は、すぐに保存されます。
3. 逸脱コメントを変えるときは、文面を編集して「コメントを保存」を押します。1行・200文字以内で、先頭の判定（「誤検知。」など）は変えません。「元に戻す」を押すと、AI の文面に戻ります。

複数のエージェントで処置しているときは、「検証」の列に結果が出た CID から選びます。検証の前に選んだ内容と編集したコメントは、検証が終わると取り消されます。

## OK を出す

選び終えたら、チャットに次のように入力します。

```text title="チャットに入力"
画面で選んだ内容で進めて
```

画面での選択が入った一覧が表示されます。あとは[一覧で決める](decide.md#答え方)と同じです。

## 閉じる

ブラウザーのタブを閉じて、チャットに「画面を閉じて」と入力します。入力しなくても、タブを閉じて30分たつと、画面のサーバーは止まります。

!!! info "画面でできないこと"
    処置の開始、修正の取り込み、Coverity への登録は、チャットで行います。画面はこの PC の中（127.0.0.1）だけで動き、保存するのは選択と編集したコメントだけです。
