# 画面で選ぶ

ブラウザーの画面で、処置の進捗と、CID ごとの修正コード・逸脱コメントを見ながら、どれを採用するかを選びます（4段階目）。1〜3段階目のどれで処置した結果も表示できます。

## 開く

`copilot` で次の文を入力します。

```text title="チャットに入力"
画面を開いて
```

この PC のブラウザーで画面が開きます。開かないときは、チャットに表示された URL を開きます。

- 2段階目・3段階目のエージェントを動かしているときは、別のターミナルで `copilot` を起動して入力します。進捗が数秒ごとに更新されます。
- Linux では、そのターミナルで先に[認証情報の3行](setup.md#2-認証情報を設定する)を実行します。OK の後に Coverity へ登録するためです。

## 選ぶ

1. 一覧の CID（例：▸ 20001）を選ぶと、根拠、修正コードの差分、逸脱コメントが開きます。
2. 「修正を取り込む」「逸脱コメントを登録する」「保留にする」から選びます。選んだ内容は、すぐに保存されます。
3. 逸脱コメントを変えるときは、文面を編集して「コメントを保存」を押します。1行、200文字以内で、先頭の判定の語（「誤検知。」など）は変えません。「元に戻す」で AI の文面に戻ります。

3段階目の処置中は、「検証」の列に結果が出た CID から選びます。検証の前に選んだ内容と編集したコメントは、検証が終わると取り消されます。

## OK を出す

選び終えたら、チャットに入力します。

```text title="チャットに入力"
画面で選んだ内容で進めて
```

画面の選択が入った一覧が表示されます。あとは[一覧で決める](decide.md#答え方)と同じです。

## 閉じる

ブラウザーのタブを閉じ、チャットに「画面を閉じて」と入力します。入力しなくても、タブを閉じてから30分たつと、画面のサーバーは止まります。

!!! info "画面が扱う範囲"
    画面は、この PC の中（127.0.0.1）だけで動きます。書き込むのは選択と編集したコメントだけで、処置の開始、取り込み、登録はチャットで行います。
