# ひな形の書き方

ひな形は、値が空の設定ファイル。`項目: 値` の形で書く。各項目のすぐ上に、コメントで説明を書く。
設定のスキルは、コメントの説明を添えて、項目を1つずつ利用者に質問する。

## 書ける形

- `項目: 値`。行頭から書く。値を空にするときは `項目:`。
- リストは、`項目:` の次の行から、`  - 値` を1行に1つずつ書く。リストの項目のコメントには、「1行に1つずつ書く」と書く。
- 入れ子や `[a, b]` の形は使わない。

## コメントに書く語

| コメントに書く語 | 設定のスキルの質問 |
| --- | --- |
| （必須） | 値が空なら、最初に質問する |
| （秘密） | パスワードの代わりに、環境変数の名前を質問する |
| 例： | 「例：」の後ろに書いた値を、選択肢に出す |
| 選べる値： | 「選べる値：」の後ろに `/` で区切って書いた値から、選んでもらう |

（秘密）の項目 `password` のすぐ下に、名前に `_env` を付けた項目 `password_env` を置く。設定のスキルは、ここに環境変数の名前を書く。

## 例

```yaml
# 機器の IP アドレスかホスト名（必須）。
# 例：192.168.1.50
host:

# ログインのパスワード（秘密）。
password:

# パスワードを入れた環境変数の名前。
password_env:

# 暗号化して送るか。
# 選べる値：no / yes
tls: no
```
