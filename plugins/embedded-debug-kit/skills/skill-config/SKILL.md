# skill-config

ほかのスキルの設定ファイルを、各項目のすぐ上のコメントだけを手がかりに、利用者に質問しながら埋める。

設定するファイルは `<作業フォルダ>/.<スキルの名前>/config.ini`。このスキル自身の設定ファイルはない。

## コマンド

Python は、Windows では `py -3`、ほかでは `python3` で動かす（下の表は `python3` で書く）。
作業フォルダで動かすか、`--workdir <作業フォルダ>` を付ける。

| すること | コマンド |
| --- | --- |
| 項目と今の値を読む。何も作らない | `python3 <このスキルのフォルダ>/scripts/config_tool.py show <スキルの名前>` |
| 1つの項目に値を書く | `python3 <このスキルのフォルダ>/scripts/config_tool.py set <スキルの名前> <項目> --stdin` |

set の値は、標準入力で渡す。2行以上なら、1行に1つのリストとして書く。空にするときは、値の行を書かない。

bash：

```bash
python3 <このスキルのフォルダ>/scripts/config_tool.py set <スキルの名前> <項目> --stdin <<'END'
<値>
END
```

PowerShell（1行目は、日本語などを化けずに渡すため）：

```powershell
$OutputEncoding = [Text.UTF8Encoding]::new($false)
@'
<値>
'@ | py -3 <このスキルのフォルダ>/scripts/config_tool.py set <スキルの名前> <項目> --stdin
```

## 結果

標準出力に JSON を1つ返す。終了コードは、0 が成功、1 が書き込めなかったとき、2 が設定ファイルや引数の問題。

| 項目 | 中身 |
| --- | --- |
| `ok` | 成功したら `true` |
| `message` | 起きたことと、確かめること。利用者にはこれを伝える |
| `problems` | 問題の一覧（終了コード 2 のとき） |
| `file` | 設定ファイルの場所（`config` も同じ） |
| `items` | show の結果。項目ごとの情報（下の表） |
| `missing` | show の結果。必須なのに空の項目 |
| `key`、`value`、`changed` | set の結果。書いた項目、書いた値、ファイルを書き換えたか（今と同じ値なら `false`） |
| `log` | set のログの場所（show はログを作らない） |

| `items` の項目 | 中身 |
| --- | --- |
| `key` | 項目の名前 |
| `value` | 今の値。2行以上の値はリスト。（秘密）の値は、空なら `""`、空でなければ `＊＊＊` |
| `required`、`secret` | コメントに「（必須）」「（秘密）」があるか |
| `examples`、`choices` | コメントの「例：」の値と、「選べる値：」の値 |
| `comment` | 項目の説明（「例：」「選べる値：」の行を除いたコメント） |
| `env_key` | （秘密）の値を入れる環境変数の名前を書く項目（`<項目>_env`）。なければ `null` |

コメントの読み方と、set の細かい決まりは [reference/file-rules.md](reference/file-rules.md) にある。

## 進め方

1. 設定するスキルの名前を決める。頼みになければ、利用者に聞く。
2. show を動かす。`ok` が `false` なら、`message` を伝えて終える。
3. `missing` の項目を、並びの順に1つずつ聞いて、set で書く。
4. ほかの項目と今の値を表にして見せ、直したい項目があるかを1回だけ聞く。あれば、同じように1つずつ聞く。
5. show をもう一度動かし、設定ファイルの場所、書いた項目、まだ空の必須の項目を伝える。設定を確かめるには、そのスキルに頼むよう勧める。

聞き方：

- 利用者に質問するツールで、1回に1つだけ聞く。`comment` を短くまとめて添える。
- 選択肢は、`choices` があればその値、なければ `examples` の値と今の値にする。
- 利用者が頼みの中で値を示した項目は、聞かずにその値を書く。
- 答えは、手を加えずに set に渡す。

（秘密）の項目（`secret` が `true`）は、値の代わりに渡し方を聞く。

- 環境変数で渡す（`env_key` があるときだけ）：環境変数の名前だけを聞き、`env_key` の項目に書く。そのあと、値の入れ方を伝える。PowerShell は `$env:<名前> = '<値>'`、bash は `export <名前>='<値>'`。値を入れた端末から、CLI を起動し直す。もとの項目に値が残っていれば（`＊＊＊`）、空にするかを聞く。
- 自分でファイルに書く：設定ファイルの場所と項目の名前を伝える。

利用者に質問できないとき（質問するツールがないときや、ほかのエージェントから頼まれたとき）は、設定ファイルの場所と `missing` を伝えて終える。

## してはいけないこと

- ほかのスキルの SKILL.md やフォルダを読まない。項目の意味は、コメントから伝える。
- （秘密）の項目の値を聞かない。チャットにもコマンドにも書かない。
- コメントにない値を、選択肢にしない。
- 利用者に質問できないときに、設定ファイルを書き換えない。
- このスクリプトのほかの方法で、設定ファイルを書き換えない。
- 設定したスキルを動かさない。
