# serial-console

シリアルポートで機器のシェルにつなぎ、コマンドを1つずつ動かして、出力と終了コードを JSON で返す。

設定ファイルは `<作業フォルダ>/.<このスキルのフォルダの名前>/config.ini`。各項目の意味は、項目のすぐ上のコメントにある。
パスワードは、設定ファイルの `login_password` か、`login_password_env` に名前を書いた環境変数で渡す。

## コマンド

`<python>` は、Windows では `py -3`、ほかでは `python3`。作業フォルダが今のフォルダと違うときは、`--workdir <作業フォルダ>` を付ける。

| すること | コマンド |
| --- | --- |
| 設定の `commands` を順に動かす | `<python> <このスキルのフォルダ>/scripts/serial_console.py run` |
| 渡したコマンドを順に動かす（設定の `commands` は使わない） | `<python> <このスキルのフォルダ>/scripts/serial_console.py run --command 'uname -a' --command 'ls /opt/app'` |
| 設定を確かめる。プロンプトが出るまで進め（必要ならログインし）、コマンドは動かさない。何も作らない | `<python> <このスキルのフォルダ>/scripts/serial_console.py check` |
| 設定ファイルをひな形から作る。もうあれば、そのままにする | `<python> <このスキルのフォルダ>/scripts/serial_console.py init` |

run は、最長でおよそ「コマンドの数 × `command_timeout_seconds`（既定 30 秒）」かかる。コマンドを動かすツールの待ち時間は、それより長くする。

`--command` の値の書き方と、機器とのやりとりの詳細は [reference/console.md](reference/console.md) にある。

## 結果

標準出力に JSON を1つ返す。終了コードは、0 が成功、1 がつながらない・ログインできない・時間切れなどの失敗、2 が設定や引数の問題。

| 項目 | 中身 |
| --- | --- |
| `ok`・`message` | 成功したかと、その説明。失敗のときは、確かめることも書いてある。利用者にはこれを伝える |
| `problems` | 設定の問題（終了コード 2 のとき）。直してから、もう一度動かす |
| `config`・`log` | 設定ファイルとログの場所。ログには、機器から届いた文字がすべて入っている（check はログを作らない） |
| `commands` | run：動かしたコマンドごとの `command`、`output`（色などの制御文字を除いた出力）、`exit_code`（機器での終了コード。読めなければ `null`）、`timed_out`（時間切れで Ctrl-C を送ったか）、`truncated`（`output` を最後の 60 行に切ったか） |
| `not_run` | run：動かさなかったコマンド |
| `ports` | ポートが見つからないとき：この PC で見つかったシリアルポート |
| `created` | init：設定ファイルを作ったか |

- `exit_code` が 0 でなくても、`ok` は `true` になる。コマンドがうまく動いたかは、`exit_code` と `output` で判断する。
- 時間切れのときは `ok` が `false` になり、残りのコマンドは `not_run` に入る。
- `truncated` が `true` なら、出力の全部は `log` にある。

## してはいけないこと

- つながらないときやログインできないときに、何も変えずに同じコマンドを繰り返さない。`message` を伝えて終える。
- 終わらないコマンド、入力を待つコマンド、シェルを抜けるコマンド（`tail -f`、`top`、`vi`、`exit` など）を動かさない。時間切れになり、残りのコマンドが動かない。
- 機器の中身を変えるコマンド（フラッシュへの書き込み、ファイルの一括の削除、パスワードの変更など）を、利用者に確かめずに動かさない。
- このスクリプトのほかの方法（端末ソフトや自分で書いたスクリプト）で、シリアルポートを使わない。
- パスワードをチャットで聞かない。設定ファイルの中身を見せるときも、パスワードは出さない。
- 頼まれていないのに、設定ファイルを作ったり書き換えたりしない。
