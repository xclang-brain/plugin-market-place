# 送る手順

`run` は、機器に1回だけつなぐ。つながらなくても、やり直さない。
送り先のフォルダ `remote_dir` に入り、なければ親から順に作る。そのあと、ファイルを1つずつ次の順に送る。

1. `<名前>.part` という名前で送る。
2. 機器のファイルのサイズ（SIZE）が、PC のファイルと同じかを確かめる。
3. `file_mode` があれば、権限を変える（SITE CHMOD）。
4. `<名前>` に名前を変える（RNFR・RNTO）。今あるファイルへの名前の変更を機器が断るときは、古いファイルを消してから変える。

## 失敗したとき

- `<名前>.part` を消して止まる。それより前のファイルは、送ったままになる。
- 古いファイルは、手順 4 まで残る。手順 4 で古いファイルを消したあとに名前を変えられないと、古いファイルもなくなる。
- 接続が切れて `<名前>.part` を消せなかったときは、`message` にそう書く。次に送れば上書きされる。

## 送り先

- 送るのは `remote_dir` の中だけ。`remote_dir` に `..` は使えない。`/` で始めないと、ログインしたときのフォルダからの場所になる。
- 機器での名前は、PC のファイルの名前のまま。名前に `\` や改行が入ったファイルは送らない。
- ファイルとフォルダの名前は UTF-8 で送る。

## FTPS

`tls = yes` のときは、FTPS（AUTH TLS）でつなぎ、ファイルも暗号化して送る（PROT P）。機器の証明書は確かめない。
