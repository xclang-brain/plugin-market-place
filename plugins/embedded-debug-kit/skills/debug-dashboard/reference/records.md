# 記録のしくみと画面の表示

## 記録のフォルダ

`<作業フォルダ>/.debug-dashboard/` に置く。Linux では、本人だけが読み書きできる権限で作る。Windows では、作業フォルダの権限をそのまま受け継ぐ。中身が `*` の `.gitignore` を置くので、Git に入らない。

| ファイル | 中身 |
| --- | --- |
| `recording` | 記録中フラグ。あれば、フックが記録する。サーバーが 30 秒ごとに書き直し、終了するときに消す |
| `server.json` | サーバーのプロセス番号・ポート・URL（トークン入り） |
| `sessions/<セッションの ID>/events.jsonl` | フックが書く記録。1行に1件 |
| `sessions/<セッションの ID>/stop` | 停止フラグ。あれば、フックがツールの呼び出しを断る。「実行を止める」を押すとでき、そのセッションで次の依頼が来たときと、画面を終了・起動したときに消える |
| `sessions/<セッションの ID>/handback-<サブエージェントの ID>` | 報告済みフラグ。自動モードで、サブエージェントが渡した最後の報告を記録したことを示す。そのサブエージェントが終わると消える |
| `logs/server.log` | サーバーの起動・終了と、断った要求 |
| `logs/hook.log` | フックが記録に失敗したときのエラー |

## 記録するもの

| もの | 残す内容 |
| --- | --- |
| 利用者の依頼、エージェントへの依頼文、エージェントの最後の報告 | そのまま（1件 8 KB まで） |
| コマンド | 先頭の 1,000 字 |
| ファイルの読み書き・検索 | ツールの名前とパスだけ |
| 利用者への質問 | 質問だけ |
| ツールの結果 | 残さない |

名前に pass・token・secret・key を含む項目の値（`名前=値`、`名前: 値`。全角の `＝`・`：` も）を `***` に替える。URL の `//利用者:パスワード@`、`-u 利用者:パスワード`、`sshpass -p パスワード` のパスワードも替える。
1つのセッションの記録は 20 MB まで。超えると、そこから後は記録せず、「お知らせ」を1件残す。記録は、新しいほうから 30 のセッションまで残す。
画面には、使われたツールを新しいほうから 300 件まで表示する。

## 記録されないとき

フックは、次のときは何もしない。

- `recording` がない、2 分より古い、またはシンボリックリンクである。
- `.debug-dashboard/` か、その中のフォルダがシンボリックリンクである。
- CLI を、画面を起動したのと違うフォルダで起動した。作業フォルダは、Claude Code では `CLAUDE_PROJECT_DIR`、Copilot CLI では `COPILOT_PROJECT_DIR` で決まる。Copilot CLI では、Git のリポジトリの中なら、そのいちばん上のフォルダになる。
- uv が見つからない。
- Claude Code の Windows で、`bash` が WSL のもの（`C:\Windows\System32\bash.exe`）になっている。
- プラグインとしてインストールしていない。Claude Code では、フックを settings.json に写して CLI を起動し直すまで記録しない。Copilot CLI は、プラグインとしてインストールしたときだけ記録する。

また、次のものは記録しない。

- バックグラウンドのサブエージェントが終わった知らせ（`<task-notification>` で始まる依頼）。「実行を止める」も解除されない。
- バックグラウンドのサブエージェントを待っている間の、メインの会話の報告。
- Copilot CLI で、メインの会話の最後の報告を、3 秒のうちに読めなかったとき。Copilot CLI はフックに最後の報告を渡さないので、CLI の会話の記録から読む。そのターンにメインの会話の発言がなかったときも、記録しない。
- そのセッションで依頼文を記録していないエージェントの報告。CLI が中で動かすエージェント（入力の候補、`/btw` など）や、画面を起動する前に依頼したエージェントがこれにあたる。`recording` が古くなっていた間（PC のスリープ中など）に依頼したものも同じ。

## 画面が表示するセッション

セッションは、CLI を起動してから終えるまでの、1つの会話である。「進み具合」と「結果」は、いちばん新しく動いたセッションを表示する。「前のセッション」でほかのセッションを選ぶと、そのセッションを表示し続ける。

## 動いているエージェント

画面は、依頼文や報告の中身を見ずに、記録にあるエージェントの名前を出す。ほかのエージェントに依頼していれば、そのエージェントの名前を出す。依頼していなければ、メインの会話のエージェントの名前を出す。判定として出すのは、名前が `debug-verifier` で終わるエージェントの報告。
