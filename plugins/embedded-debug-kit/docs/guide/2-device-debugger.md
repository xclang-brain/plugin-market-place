# 作業エージェントの使い方

不具合の調査と修正を、AI に任せます。
AI が、ソースを直し、ビルドし、機器で動かして確かめることを、直るまで繰り返します。

## 手順

1. 直したいソースのフォルダで、作業エージェントを指定して CLI を起動します。

   ```shell
   copilot --agent embedded-debug-kit:device-debugger
   ```

   起動した後に指定するときは、`/agent` と入力して、一覧から選びます。Claude Code では、`copilot` を `claude` に読み替えます。

2. 初めて使うときは、「スキルを設定したい」と依頼し、AI の質問に答えます。ビルドのコマンドや、機器のアドレスを設定します。
3. 起きている症状と、正しい結果を書いて依頼します。

   ```text
   sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
   ```

4. AI が、直ったか、原因、変えたファイル、ログの場所を報告します。

試す回数の上限は、5回です。「3回まで」「main.c は変えない」のように依頼に書くと、そのとおりにします。

## してはいけないこと

- コミットしていない変更があるフォルダで使わないでください。AI がソースを書き換えます。コミットしておけば、`git diff` で変更を確かめて戻せます。
- パスワードをチャットに書かないでください。
