# 作業エージェントの使い方

作業エージェントは、不具合の原因を調べて直す AI です。
ソースを直し、ビルドして機器で動かし、結果を確かめる作業を、直るまで、最大5回繰り返します。

## 手順

1. 直したいソースの変更を、コミットしておきます。AI がソースを書き換えるためです。
2. ソースのフォルダで、作業エージェントを指定して CLI を起動します。

   ```shell
   copilot --agent embedded-debug-kit:device-debugger
   ```

   Copilot CLI では、起動した後に `/agent` と入力して、一覧から選ぶこともできます。Claude Code では、`claude --agent embedded-debug-kit:device-debugger` で起動します。

3. 初めて使うときは、「スキルを設定したい」と依頼し、AI の質問に答えます。ビルドのコマンドや、機器のアドレスを設定します。
4. 起きている症状と、正しい結果を書いて依頼します。

   ```text
   sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
   ```

5. AI が、直ったかどうか、原因、変えたファイル、ログの場所を報告します。変更は、`git diff` で確かめます。

「3回まで」「main.c は変えない」のように依頼に書くと、AI はそのとおりに進めます。

## してはいけないこと

- コミットしていない変更があるフォルダで使わないでください。AI の変更と区別できなくなります。
- パスワードをチャットに書かないでください。
