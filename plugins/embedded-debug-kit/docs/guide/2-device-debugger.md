# 作業エージェント（device-debugger）

組み込み機器で動く C/C++ プログラムの不具合を、AI が実機で試しながら直します。
ソースを直し、ビルドして機器に送り、機器で動かしてログで確かめます。この試行を、直るまで繰り返します。

## 始め方

1. プラグインを入れます（[入れ方](../../README.md#入れ方)）。
2. 直したいソースのフォルダで、作業エージェントを指定して CLI を起動します。

   ```shell
   # Claude Code
   claude --agent embedded-debug-kit:device-debugger
   # GitHub Copilot CLI（起動してから /agent で選んでもかまいません）
   copilot --agent embedded-debug-kit:device-debugger
   ```

3. 初めて使うときは、「スキルを設定したい」と依頼します。質問に答えると、ビルドの方法や機器への接続を設定できます。

## 依頼のしかた

起きている症状と、正しい結果を書きます。

```text
sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
```

必要なら、次のことも書けます。

- 合格の条件（例：ログに AVG=25 と出る）。書かなければ、正しい結果から決めて伝えます。
- 試行の上限（例：3回まで）。書かなければ5回です。
- 変えてはいけないファイル（例：main.c は変えない）。

終わると、直ったか、原因、変えたファイル、試行ごとの結果、ログの場所を報告します。
直すほかに、「機器で1回動かして、結果を見せて」「設定を確かめて」とも依頼できます。

## 使うスキル

次のスキルを使います。

- ビルド：[cross-build](1-cross-build.md)
- 機器への転送：[ftp-deploy](1-ftp-deploy.md)
- 機器での実行とログの取得：[serial-console](1-serial-console.md)
- 設定：[skill-config](1-skill-config.md)

設定の項目は、各スキルの使い方にあります。

## 困ったとき

| 起きること | すること |
| --- | --- |
| エージェントが見つからないと言われる | プラグインが入っていて、有効かを確かめる（`claude plugin list` か `copilot plugin list`） |
| 設定が足りないと言われる | 「スキルを設定したい」と依頼する |
| 機器とやり取りできない | 機器の電源、ケーブル、設定を確かめる |

## してはいけないこと

- コミットしていない変更があるフォルダで使わないでください。AI はソースを直接書き換え、自動では元に戻しません。始める前にコミットしておくと、`git diff` で確かめて戻せます。
- パスワードをチャットに書かないでください。
