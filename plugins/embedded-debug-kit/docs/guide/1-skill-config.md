# skill-config の使い方

cross-build、ftp-deploy、serial-console を使う準備をするスキルです。最初に1回使います。
設定ファイルを作り、AI の質問に答えた値を書き、スクリプトに必要なパッケージを入れます。

## 手順

1. 機器のパスワードを、環境変数に入れます。環境変数の名前は自由です（例：`DEVICE_PASSWORD`）。
2. 同じターミナルで、ソースのフォルダで CLI を起動し、「スキルを使う準備をして」と依頼します。
3. AI の質問に、1つずつ答えます。パスワードの渡し方を質問されたら、手順 1 の環境変数の名前を答えます。

ソースのフォルダに、スキルごとの設定ファイル `.<スキルの名前>/config.yaml` ができます。

1つの項目だけを変えるときは、「ftp-deploy の host を 192.168.1.50 にして」のように依頼します。

スキルを名前で指定して呼ぶときは、`/embedded-debug-kit:skill-config スキルを使う準備をして` と入力します。

## してはいけないこと

- パスワードをチャットに書かないでください。
- エディターで設定ファイルを編集している間は、AI に設定させないでください。編集中のエディターで保存すると、AI が書いた値が上書きされます。
