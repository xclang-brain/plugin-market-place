# skill-config の使い方

質問に答えるだけで、AI が設定ファイルに値を書くスキルです。
cross-build、ftp-deploy、serial-console の設定に使えます。

## 手順

ftp-deploy を例にします。ほかのスキルも、名前を変えて同じようにします。

1. 機器の FTP のパスワードを、環境変数に入れます。環境変数の名前は自由です（例：`DEVICE_FTP_PASSWORD`）。
2. 同じターミナルで、ソースのフォルダで CLI を起動し、「ftp-deploy の設定ファイルを作って」と依頼します。値が空の設定ファイルができます。
3. 「ftp-deploy の設定を、質問しながら埋めて」と依頼します。
4. AI の質問に、1つずつ答えます。パスワードの渡し方を質問されたら、手順 1 の環境変数の名前を答えます。

1つの項目だけを変えるときは、「ftp-deploy の host を 192.168.1.50 にして」のように依頼します。

スキルを名前で指定して呼ぶときは、`/embedded-debug-kit:skill-config ftp-deploy の設定を、質問しながら埋めて` と入力します。

## してはいけないこと

- パスワードをチャットに書かないでください。
- エディターで設定ファイルを編集している間は、AI に設定させないでください。編集中のエディターで保存すると、AI が書いた値が上書きされます。
