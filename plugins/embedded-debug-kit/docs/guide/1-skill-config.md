# skill-config の使い方

スキルの設定ファイルの値を、AI の質問に答えて書くスキルです。
cross-build、ftp-deploy、serial-console の設定に使えます。

## 手順

ftp-deploy を設定する例です。

1. 「ftp-deploy の設定ファイルを作って」と依頼します。
2. 「ftp-deploy の設定を、質問しながら埋めて」と依頼します。
3. AI の質問に、1つずつ答えます。
4. AI が、設定ファイルの場所と、書いた項目を伝えます。

1つの項目だけを変えるときは、「ftp-deploy の host を 192.168.1.50 にして」のように依頼します。

スキルを指定するときは、`/embedded-debug-kit:skill-config ftp-deploy の設定を埋めて` と入力します。

## パスワード

パスワードを聞かれたら、環境変数の名前を答えます。値を環境変数に入れるコマンドは、AI が伝えます。
設定ファイルに自分で書くこともできます。

## ログ

書き換えた項目は、`.skill-config/logs/` に残ります。パスワードは `***` に置き換わります。

## してはいけないこと

- パスワードをチャットに書かないでください。
- 設定ファイルをエディターで開いて書きかけのまま、AI に設定させないでください。あとで保存すると、AI が書いた値が消えます。
