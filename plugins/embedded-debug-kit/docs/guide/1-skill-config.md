# skill-config の使い方

スキルの設定を、AI の質問に答えて済ませるスキルです。
cross-build、ftp-deploy、serial-console の設定に使えます。

## 必要なもの

- Python 3.8 以上（Windows では `py -3`、ほかの OS では `python3` で動くもの）

## 依頼のしかた

ftp-deploy を設定する例です。

1. 「ftp-deploy の設定ファイルを作って」と依頼します。
2. 「ftp-deploy の設定を、質問しながら埋めて」と依頼します。
3. AI が、必須の項目を1つずつ質問します。選択肢から選ぶか、値を書いて答えます。
4. AI が、残りの項目と今の値を表で示します。変えたい項目があれば、伝えます。
5. AI が、設定ファイルの場所と、書いた項目を伝えます。

1つの項目だけを変えるときは、「ftp-deploy の host を 192.168.1.50 にして」のように、値まで書いて依頼します。

スキルを指定して呼ぶときは、スラッシュコマンドを使います。

```text
/embedded-debug-kit:skill-config ftp-deploy の設定を埋めて
```

## パスワードの渡し方

パスワードは、チャットに書かずに渡します。AI が、次のどちらにするかを質問します。

| 渡し方 | すること |
| --- | --- |
| 環境変数で渡す | 環境変数の名前を答える。値を設定するコマンドは、AI が伝える |
| 設定ファイルに自分で書く | AI が伝えた設定ファイルを開き、値を書く |

## 結果とログ

- 書き換えるのは、答えた項目の行だけです。ほかの行とコメントは、そのまま残ります。
- 書き換えに失敗したときは、設定ファイルは元のままです。
- 書き換えの記録は、`<作業フォルダ>/.skill-config/logs/` に残ります。パスワードは `***` と書きます。

## 設定ファイルの決まり

自分で作ったスキルも、設定ファイルを次の決まりで書けば、skill-config で設定できます。

- 置き場所は、`<作業フォルダ>/.<スキルの名前>/config.yaml` です。
- `項目: 値` と、`- 値` のリストで書きます。
- 項目のすぐ上のコメントに、説明と、次のキーワードを書きます。

| キーワード | skill-config の動き |
| --- | --- |
| （必須） | 値が空なら、最初に質問する |
| （秘密） | 値の代わりに、渡し方を質問する |
| 例： | 続く値を、選択肢に出す |
| 選べる値： | `/` で区切った値の中から、選んでもらう |

（秘密）の項目 `password` には、環境変数の名前を書く項目 `password_env` を添えます。

```yaml
# 機器の IP アドレスかホスト名（必須）。
# 例：192.168.1.50
host:

# ログインのパスワード（秘密）。
password:

# パスワードを入れた環境変数の名前。
# 例：DEVICE_PASSWORD
password_env:

# FTPS を使うか。
# 選べる値：no / yes
tls: no

# 送るファイル（必須）。
files:
  - build/my_app
  - conf/my_app.conf
```

## 困ったとき

| 起きること | すること |
| --- | --- |
| 日本語の値が `?` になる | Windows PowerShell 5.1 で起きる。PowerShell 7 を使う |
| 「その項目の行だけを書き換えられない」と言われる | 設定ファイルを開いて、直接直す |

## してはいけないこと

- パスワードをチャットに書かないでください。
- 設定ファイルをエディターで開いて書きかけのまま、AI に設定させないでください。あとで保存すると、AI が書いた値が消えます。
- `.<スキルの名前>/` の `.gitignore` を消さないでください。パスワードを書いた設定ファイルが、Git に入ります。
