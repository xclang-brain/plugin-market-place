# skill-config の使い方

質問に答えるだけで、AI が設定ファイルに値を書くスキルです。
cross-build、ftp-deploy、serial-console の設定に使えます。

## 手順

1. 「ftp-deploy の設定ファイルを作って」と依頼します。値が空の設定ファイルができます。
2. 「ftp-deploy の設定を、質問しながら埋めて」と依頼します。
3. AI の質問に、1つずつ答えます。終わると、AI が、書いた項目を報告します。

1つの項目だけを変えるときは、「ftp-deploy の host を 192.168.1.50 にして」のように依頼します。

スキルを指定して呼ぶときは、`/embedded-debug-kit:skill-config ftp-deploy の設定を、質問しながら埋めて` と入力します。

## パスワード

パスワードは、環境変数で渡します。

1. AI がパスワードの渡し方を質問したら、環境変数の名前を決めて答えます（例：`DEVICE_FTP_PASSWORD`）。
2. CLI を終了し、AI が示したコマンドで、その環境変数にパスワードを入れます。
3. 同じターミナルで、CLI を起動し直します。

パスワードを、設定ファイルに自分で書くこともできます。

## してはいけないこと

- パスワードをチャットに書かないでください。
- エディターで設定ファイルを編集している間は、AI に設定させないでください。エディターで保存すると、AI が書いた値が消えます。
