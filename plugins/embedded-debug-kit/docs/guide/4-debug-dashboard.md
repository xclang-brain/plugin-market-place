# Web管理画面の使い方

作業エージェントや統括エージェントの進み具合と結果を、ブラウザーで見る画面です。スキルの設定も、この画面で変えられます。

## 手順

1. スキルを使う準備（[作業エージェントの使い方](2-device-debugger.md)の手順 1〜4）と、ソースの変更のコミットを済ませます。
2. ソースのフォルダで CLI を起動し、`/embedded-debug-kit:debug-dashboard` と入力します。画面の URL が出ます。
3. URL をブラウザーで開きます。
4. 別のターミナルで、同じフォルダから、エージェントを起動して依頼します。
   - 1つの AI に任せるとき：[作業エージェントの使い方](2-device-debugger.md)の手順 3、5
   - 直ったかを別の AI に判定させるとき：[統括エージェントの使い方](3-debug-orchestrator.md)の手順 3〜5
5. 「進み具合」のタブで経過を、「結果」のタブで報告を見ます。
6. 使い終わったら、手順 2 の CLI で `/embedded-debug-kit:debug-dashboard stop` と入力し、画面を終了します。

## スキルの設定を変える

「設定」のタブで、値を変えます。変えた値は、すぐに設定ファイルに書かれます。
設定ファイルに項目を足したときは、「読み直す」を押します。
パスワードの欄はありません。パスワードを入れた環境変数の名前を、`password_env` などの欄に入れます。

## 実行を止める

「進み具合」のタブの「実行を止める」を押します。
エージェントは、実行中のコマンドが終わった時点で止まり、そこまでの結果を報告します。

## してはいけないこと

- 画面の URL を、ほかの人に渡さないでください。URL を知っている人は、だれでも実行を止めることができます。
- パスワードを、依頼文やチャットに書かないでください。画面を起動している間、依頼と報告は `.debug-dashboard/` に記録されます。
