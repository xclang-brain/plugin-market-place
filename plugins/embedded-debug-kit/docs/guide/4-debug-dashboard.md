# Web管理画面の使い方

統括エージェントの進み具合と結果を、ブラウザーで見る画面です。依頼文を作ることと、実行を止めることもできます。

## 手順

1. 直したいソースのフォルダで CLI を起動し、`/embedded-debug-kit:debug-dashboard` と入力します。画面の URL が出ます。
2. URL をブラウザーで開きます。
3. 「設定」のタブに、直したいこと、合格の条件、試行の上限を入力し、できた依頼文をコピーします。
4. 別のターミナルで、同じフォルダから統括エージェントを起動し、依頼文を貼り付けて送ります（[統括エージェントの使い方](3-debug-orchestrator.md)）。
5. 「進み具合」のタブで経過を、「結果」のタブで報告と判定を見ます。
6. 使い終わったら、`/embedded-debug-kit:debug-dashboard stop` と入力して、画面を終了します。

Claude Code では、`/debug-dashboard` と入力します。

## 実行を止める

「進み具合」のタブの「実行を止める」を押します。AI は、動かしているコマンドが終わると止まり、そこまでの結果を報告します。

## 記録

画面を動かしている間、AI への依頼と、AI の報告が、`.debug-dashboard/` に記録されます。

## してはいけないこと

- 画面の URL を、ほかの人に渡さないでください。URL を開くと、実行を止められます。
- パスワードを、依頼文やチャットに書かないでください。記録に残ります。
