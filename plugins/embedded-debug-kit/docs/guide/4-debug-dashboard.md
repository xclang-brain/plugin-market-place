# Web管理画面の使い方

統括エージェントの進み具合と結果を、ブラウザーで見る画面です。

## 手順

1. スキルの設定（[作業エージェントの使い方](2-device-debugger.md)の手順 1〜4）と、ソースの変更のコミットを済ませます。
2. ソースのフォルダで CLI を起動し、`/embedded-debug-kit:debug-dashboard` と入力します。画面の URL が出ます。
3. URL をブラウザーで開きます。
4. 「設定」のタブで、「直したいこと」「合格の条件」「試行の上限」を入力します。画面に出た依頼文をコピーします。
5. 別のターミナルで、[統括エージェントの使い方](3-debug-orchestrator.md)の手順 3〜4 のとおりに統括エージェントを起動し、依頼文を貼り付けて送ります。
6. 「進み具合」のタブで経過を、「結果」のタブで報告と判定を見ます。
7. 使い終わったら、手順 2 の CLI で `/embedded-debug-kit:debug-dashboard stop` と入力し、画面を終了します。

## 実行を止める

「進み具合」のタブの「実行を止める」を押します。
統括エージェントは、実行中のコマンドが終わった時点で止まり、そこまでの結果を報告します。

## してはいけないこと

- 画面の URL を、ほかの人に渡さないでください。URL を知っている人は、だれでも実行を止めることができます。
- パスワードを、依頼文やチャットに書かないでください。画面を起動している間、依頼と報告は `.debug-dashboard/` に記録されます。
