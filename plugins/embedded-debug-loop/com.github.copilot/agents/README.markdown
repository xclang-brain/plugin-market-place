# 作業エージェント（device-worker）

作業エージェント（`device-worker`）は、組み込み機器の不具合をチャットで調べて直す AI です。
ソースを直し、スキルでビルド・機器への転送・ログ取得をして、直ったかをログで確認します。

- 変えるのは、作業フォルダ（ふつうは、Copilot CLI を起動したフォルダ）のソースと、セットアップで答えた設定だけです。
- 変えてはいけないファイルがあれば、頼みに書きます。

## 始め方

1. プロジェクトのフォルダで、Copilot CLI を起動します。
2. `/agent` で `device-worker · plugin` を選びます。
3. チャットで頼みます。

`/clear` の後は、もう一度 `/agent` で選びます。

## 頼み方の例

### セットアップ

```text
セットアップしたい
```

使うスキルの設定を、質問に答えて埋めます。
一部だけ直すときは、「転送の設定だけ直したい」のように頼みます。

### 不具合の調査と修正

```text
sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
```

- 合格の条件（例：「ログに AVG=25 と出る」）、試行の上限（例：「3回まで」）、守ること（例：「main.c は変えないで」）も書けます。
- 修正 → ビルド → 転送 → ログ取得 を、直るまで繰り返します。上限は、書かなければ 5 回です。
- 終わると、結論（直ったか、原因、変えたところ）、試行ごとの結果、ログの場所を報告します。

### ほかの頼み

- 「ビルドして、機器で動かして、ログを見せて」：1回だけ動かして、結果とログを見せます。
- 「設定を確認して」：設定と、機器への接続を確認します。

## 使うスキル

作業エージェントは、次のスキルを名前で呼びます。
設定の項目や、機器との接続に要るものは、各スキルの README にあります。

| 役割 | スキル |
| --- | --- |
| ビルド | [`cross-compile`](../../skills/cross-compile/README.md) |
| 機器への転送 | [`deploy`](../../skills/deploy/README.md) |
| 機器のログ取得 | [`log-capture`](../../skills/log-capture/README.md) |
| 設定（セットアップ） | [`setup`](../../skills/setup/README.md) |

スキルを置き換える方法は、[スキルと作業エージェントを置き換える](../../docs/guide/replace.md) にあります。

## うまくいかないとき

| 起きること | すること |
| --- | --- |
| `/agent` の一覧に `device-worker · plugin` がない | プラグインがインストールされているかを確認する（[インストール](../../README.md#インストール)） |
| 設定が足りないと言われる | 「セットアップしたい」と頼む |
| 転送やログ取得が失敗する | 機器の電源、ケーブル、設定を確認する。作業エージェントは同じ操作を繰り返さず、どうするかを質問する |
| スキルを使えないと言われる | `/skills list` で、上の表のスキルが読み込まれているかを確認する |
| 思っていたのと違うスキルが使われる | 作業フォルダの `.github/skills/` や `~/.copilot/skills/` などに同じ名前のスキルがあると、そちらが使われる。`/skills list` で場所を確認する |
