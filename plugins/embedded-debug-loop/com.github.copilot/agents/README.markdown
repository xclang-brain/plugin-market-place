# 作業エージェント（device-worker）

作業エージェント（`device-worker`）は、組み込み機器の不具合をチャットで調べて直す AI です。
ソースを直し、スキルを使って機器で試し、直ったかを確かめます。

- 変えるのは、作業フォルダ（ふつうは、Copilot CLI を起動したフォルダ）のソースと、セットアップで決めた設定だけです。
- 変えてはいけないファイルがあれば、依頼に書きます。

## 始め方

1. プロジェクトのフォルダで、Copilot CLI を起動します。
2. `/agent` で `device-worker · plugin` を選びます。
3. チャットで頼みます。

`/clear` の後は、もう一度 `/agent` で選びます。

## 依頼の例

### セットアップ

```text
セットアップしたい
```

使うスキルの設定を埋めます。質問に答えるか、案内された設定ファイルに自分で書きます。
一部だけ直すときは、「<スキルの名前> の設定だけ直したい」のように頼みます。

### 不具合の調査と修正

```text
sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
```

- 合格の条件（例：「ログに AVG=25 と出る」）、試行の上限（例：「3回まで」）、守ること（例：「main.c は変えないで」）も書けます。
- 修正と、スキルでの試行を、直るまで繰り返します。上限は、書かなければ 5 回です。
- 終わると、結論（直ったか、原因、変えたところ）、試行ごとの結果、ログの場所を報告します。

### ほかの依頼

- 「機器で試して、結果を見せて」：1回だけ試して、結果を見せます。
- 「設定を確認して」：設定と、機器への接続を確認します。

## 使うスキル

使うスキルは、[作業エージェントの定義](device-worker.agent.md#使うスキル)の「使うスキル」の表にあります。
設定の項目や、機器との接続に要るものは、各スキルの README（[skills/](../../skills/) の下のフォルダ）にあります。

## うまくいかないとき

| 起きること | すること |
| --- | --- |
| `/agent` の一覧に `device-worker · plugin` がない | プラグインがインストールされているかを確認する（[インストール](../../README.md#インストール)） |
| 設定が足りないと言われる | 「セットアップしたい」と頼む |
| 機器とのやり取りが失敗する | 機器の電源、ケーブル、設定を確認する。作業エージェントは同じ操作を繰り返さない。そのときに使うスキルがあれば、使ってよいかを質問し、1回だけやり直す |
| スキルを使えないと言われる | `/skills list` で、「使うスキル」の表のスキルが読み込まれているかを確認する |
| 思っていたのと違うスキルが使われる | 作業フォルダの `.github/skills/` や `%USERPROFILE%\.copilot\skills\` などに同じ名前のスキルがあると、そちらが使われる。`/skills list` で場所を確認する |
