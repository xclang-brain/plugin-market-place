# スキルと作業エージェントを置き換える

スキルか作業エージェントを置き換えると、ほかの部品を変えずに、別の方法や別の機器で使えます。
作業の方法（ビルド・転送・ログ取得のしかた）が違うときはスキルを、機器の種類が違うときは作業エージェント（`device-worker`）を置き換えます。

## スキルを置き換える

プロジェクトにプラグインのスキルと同じ名前のスキルを置くと、Copilot CLI はプロジェクトのスキルを使います。
作業エージェントは変えません。

新しいスキルは、次の約束を守ります。

| 約束 | 内容 |
| --- | --- |
| 名前 | `SKILL.md` の `name:` を、置き換えるスキルと同じ名前にする。フォルダの名前も同じにする |
| 作業 | 役割の作業を頼まれたら、作業をして、成否・起きたこと・ログの場所を返す |
| 設定の確認 | 頼まれたら、設定の抜けや誤りを返す。できれば、機器に接続できるかも試す |
| 設定の説明 | 設定が要るなら、`README.md` に設定ファイルの場所・作り方・項目の意味を書く。設定のスキルがこれを読み、利用者に聞きながら埋める |
| 独立 | フォルダの中だけで動く。ほかのスキルやエージェントを前提にしない |

手順：

1. 新しいスキルのフォルダを、作業フォルダ（ふつうは、Copilot CLI を起動したフォルダ）の `.github/skills/<置き換えるスキルの名前>/` に置きます。
2. Copilot CLI で `/skills reload` を実行します。`/skills list` で、そのスキルが「project」の下に出れば成功です。
3. 元のスキルの設定ファイルが、新しいスキルの設定ファイルと同じ場所にあれば、消すか名前を変えます。
4. `/agent` で作業エージェントを選び、「セットアップしたい」と頼みます。質問に答えて、新しいスキルの設定を埋めます。
5. 「設定を確認して」と頼みます。問題がなければ完了です。

元のスキルも残すときは、新しいスキルを別の名前で置きます。作業エージェントのコピーを作り、「使うスキル」の表の名前を書き換えます（次の節）。

## 作業エージェントを置き換える

作業エージェントの定義をコピーして書き換え、3段階目では Web管理画面で選びます。
統括エージェント（`orchestrator`）・検証エージェント（`verifier`）・Web管理画面は変えません。

統括エージェントは、次の形で頼み、次の形の返事を受け取ります。新しい作業エージェントも、これを守ります。

| 場面 | 約束 |
| --- | --- |
| ほかのエージェントから呼ばれたとき（ask_user が使えないか、頼みが「これは準備の確認です」か「あなたは作業役です」で始まる） | 利用者に質問せず、頼まれたことだけをする |
| 準備の確認 | 作業はしない。1行目に「準備：できている」か「準備：できていない」と書き、続けて設定の要約と、足りないもの（直し方つき）を書く |
| 試行 | 1回だけ作業し、合否は判断しない。進めなくなったら止める。変えたこと、手順ごとの「できた／できなかった（理由）」、ログの要点、ログの場所（絶対パス）、気づいたことを返す |

手順：

1. プラグインの `device-worker.agent.md`（[GitHub](https://github.com/xclang-brain/plugin-market-place/tree/main/plugins/embedded-debug-loop/com.github.copilot/agents)）を、作業フォルダの `.github/agents/<新しい名前>.agent.md` にコピーします。
2. コピーしたファイルを書き換えます。
   - 先頭の `description` と最初の段落：何をするエージェントか。Web管理画面で選ぶときに、この説明が出ます。
   - 「使うスキル」の表：使うスキルの名前。名前の前に `<プラグインの名前>:` は付けません。
   - ファイルの中の `device-worker`：新しい名前。「device-worker · plugin」は「<新しい名前> · project」にします。
   - 作業の言葉（「ビルド」「転送」など）、例、「調べ方のこつ」：その機器に合う内容。
   - 「変えてよいもの」の「このプラグインのファイル」：「このエージェントのファイル」。
3. 上の表の約束にあたる部分は、言葉を変えても、決まりを変えません。「2つの使われ方」、「B-1」（準備の確認）、「B-2」（試行）、「うまくいかなかったとき」の「B では」の行です。
4. `/agent` で新しいエージェントを選び、単体で動くことを確認します。
5. 3段階目で使うときは、Web管理画面の「設定」で、作業エージェントに新しい名前を選びます。統括エージェントへの依頼に「作業エージェントは <名前> で」と書いても選べます。
