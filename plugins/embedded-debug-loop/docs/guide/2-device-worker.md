# 作業エージェント（device-worker）

組み込み機器で動く C/C++ プログラムの不具合を、AI が実機で試しながら直します。
ソースを直し、ビルドして機器で動かし、ログで直ったかを確かめることを、直るまで繰り返します。

## 使い方

1. `/agent` を入力し、一覧から `device-worker` を選びます。
2. 初めて使うときは、「セットアップしたい」と頼みます。質問に答えると、機器への接続などの設定ができます。
3. 直してほしい不具合を頼みます。

## 頼み方

起きている症状と、正しい結果を書きます。

```text
sensor_app を機器で動かすと、AVG=3 と出ます。正しくは AVG=25 です。原因を調べて直してください。
```

必要なら、次のことも書けます。

- 直ったとみなす条件（例：ログに AVG=25 と出る）。書かなければ、正しい結果から決めます。
- 試す回数の上限（例：3回まで）。書かなければ 5 回です。
- 変えてはいけないファイル（例：main.c は変えない）。

終わると、直ったか、原因、変えたファイル、試行ごとの結果、ログの場所を報告します。

直すほかに、「機器で動かして、結果を見せて」「設定を確かめて」とも頼めます。

## 注意

- AI は、Copilot CLI を起動したフォルダのソースを直接書き換え、自動では元に戻しません。始める前にコミットしておくと、`git diff` で確かめて戻せます。
- AI が変えるのは、ソースと、セットアップで作る設定ファイルだけです。
- 機器とやり取りできないときは、同じ操作を繰り返さずに止まり、どうするかを聞きます。

## うまくいかないとき

| 起きること | すること |
| --- | --- |
| `/agent` の一覧に `device-worker` がない | プラグインがインストールされているかを確かめる（[インストール](../../README.md#インストール)） |
| 設定が足りないと言われる | 「セットアップしたい」と頼む |
| 機器とやり取りできない | 機器の電源、ケーブル、設定を確かめる |
| 思っていたのと違うスキルが使われる | 同じ名前のスキルがほかの場所にあると、そちらが使われる。`/skills list` で場所を確かめる |

## 使うスキル

使うスキルは、[作業エージェントの定義](../../com.github.copilot/agents/device-worker.agent.md#使うスキル)にあります。
機器に要るものと設定の項目は、スキルごとのガイド（このフォルダの `1-<スキルの名前>.md`）にあります。
