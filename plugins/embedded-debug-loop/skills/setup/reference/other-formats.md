# YAML 以外の形式（INI・JSON など）と、道具が読めない YAML

道具（`show`・`set`）は使いません。ファイルは、ファイルを読むツールと編集のツールで扱います。

- 項目の意味・必須か・例・選べる値は、項目のすぐ上のコメントと、設定するスキルの SKILL.md から読みます。
  YAML のときと同じく、「必須」「必ず」「例：」「選べる値：」の言葉で見分けます。
- 聞く順番と質問のしかたは、YAML のときと同じです。
- 書き換えるのは、その項目の値の部分だけです。コメント・空行・並びは変えません。
  値は、その形式の書き方に合わせます。書き方が分からなければ書かず、そう伝えます。
- パスワードなどの項目（名前か SKILL.md から分かるもの）は [secrets.md](secrets.md) のとおりに聞きます。
  ただし「書き換えた」と答えられても読み直さず、報告の表では値を「（確かめていません）」にします。
- 報告の表は、列が「項目」「値」の表を自分で作ります。空の値は「（空）」、パスワードなどは「＊＊＊」と書きます。
