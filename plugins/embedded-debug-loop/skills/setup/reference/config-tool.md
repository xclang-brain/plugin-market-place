# 道具（config_tool.py）

YAML の設定ファイルを読み書きする道具です。結果はいつも JSON で、`"ok": false` のときは `error` に理由があります。

## サブコマンド

| サブコマンド | すること |
| --- | --- |
| `show <ファイル>` | ファイルの説明と、項目ごとの説明・今の値・例を返す |
| `set <ファイル> <項目> --stdin` | 標準入力の値を、文字として書く |
| `set <ファイル> <項目> --stdin --json` | 標準入力の値を JSON として読み、数・true/false・リストを書く |
| `get <ファイル> <項目>` | 1つの項目の今の値を返す |

- `<ファイル>` は、作業フォルダからの場所か絶対パスです。作業フォルダが今のフォルダと違うときは `--workdir <フォルダ>` を付けます。
- ファイルがないとき、`show` は `"exists": false` を返します。
- `set` は、その項目の行だけを書き換えます。コメントと並びは変えません。ない項目、種類の違う値、`choices` にない値は断ります。
- 空の値を書くときは、`<値>` の行を書きません。空のリストは `--json` で `[]` です。
- PowerShell の `@'` は行の最後に、`'@` は行の先頭に書きます。`'` を外すと、値の中の `$` などが置き換わります。
- 道具が読めない書き方（入れ子など）のファイルでは、`"unsupported": true` が返ります。

## `show` の結果

| 名前 | 中身 |
| --- | --- |
| `exists` | ファイルがあれば true |
| `header` | ファイルの先頭のコメント（何のファイルか） |
| `missing` | 必須なのに空の項目 |
| `table` | 項目と値の表。報告にそのまま貼る（パスワードなどは伏せてある） |
| `items` | 項目ごとの情報（次の表） |

| `items` の名前 | 中身 |
| --- | --- |
| `key`・`comment`・`value` | 項目の名前・すぐ上のコメント・今の値 |
| `type` | `string`・`number`・`boolean`・`list`・`null` |
| `required` | 必須の項目 |
| `fill_recommended` | 必須ではないが、コメントに「必ず書く」とある項目 |
| `empty`・`can_be_empty` | 値が空か・空にしてよいか |
| `examples`・`choices` | コメントの「例：」と「選べる値：」の値 |
| `secret` | パスワードなど、見せない値（値は `＊＊＊` で返る） |
| `value_digest` | `secret` の値の指紋。書き換わったかを見分けるだけに使い、利用者には見せない |
| `env_alternative` | 同じ値を環境変数で渡すための項目の名前 |
| `env_for`・`ask_alone` | 環境変数の名前を書く項目なら、もとの項目の名前と false。この項目だけを聞くことはしない |
| `env_defined` | 書いてある名前の環境変数が、今のシェルにあれば true |
