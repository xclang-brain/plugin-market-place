# パスワードなど（`secret` が true の項目）

値は、チャットの文にも表にも書きません。今の値は、空なら「（空）」、空でなければ「＊＊＊」と書きます。

渡し方を ask_user で聞きます。

1. 環境変数で渡す（おすすめ。値をチャットにもファイルにも書きません）… `env_alternative` があるときだけ
2. 自分でファイルを書き換える（値はチャットに出ません）
3. ここで入力して書き込む（入力した値は、Copilot CLI の画面と記録に残ります）
4. 今のまま

`env_alternative` がなければ、2 をおすすめにします。

## 環境変数で渡す

1. `env_alternative` の項目に、環境変数の名前を聞いて書きます。
2. 値を環境変数に入れるのは利用者です。次を伝えます。
   「Copilot CLI を一度終え、同じ端末で次を実行してから、起動し直してください。
   PowerShell：`$env:名前 = '値'`　bash：`export 名前='値'`」
3. もとの項目に値が入っていれば、消すかを聞きます。

## 自分でファイルを書き換える

1. ファイルの場所と項目の名前を伝え、「書き換えたら教えてください。」と聞きます（選択肢：「書き換えた」「あとでやる」）。
2. 「書き換えた」なら、`show` で読み直し、その項目の `empty` と `value_digest` を前と比べます。
   変わっていれば次に進みます。同じなら、まだ書き換わっていないと伝えて、もう一度聞きます。
3. 「あとでやる」なら、報告で「あとで書き換える項目」として伝えます。

## ここで入力して書き込む

値を、選択肢なしの ask_user で聞き、ほかの項目と同じく標準入力で `set` に渡します。
