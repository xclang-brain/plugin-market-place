# log-capture：シリアルコンソールの記録

## 何をするスキルか

- PC から、機器のシリアルコンソールにつなぎます。
- 機器がログインを求めたら、設定のユーザー名でログインします。
- 設定したコマンドを、機器のシェルで順に実行し、出力を記録します。
- 機器から届いた文字は、すべてログのファイルに残します。

## 設定ファイル

- 場所は、作業フォルダの `.embedded-debug-loop/log-capture.yaml` です。
- 作業フォルダは、ふつうは今のフォルダです。
- ファイルがなければ、スクリプトがひな形から作ります。
- 各項目の意味は、項目のすぐ上のコメントに書いてあります。

## 頼まれ方と、すること

下の `<このスキルのフォルダ>` は、このスキルを読み込んだときに示されるフォルダです。
コマンドは、作業フォルダで実行します。

### 1. 「ログを取って」「機器で動かして出力を見せて」と頼まれたとき

```
python3 <このスキルのフォルダ>/scripts/capture.py run
```

- 設定の commands を、機器のシェルで上から順に実行します。
- 今回だけ別のコマンドを実行するときは、`--command` を付けます。
  何回でも書けます。例：`run --command "/opt/sensor/sensor_app"`
- コマンドを実行せず、出力を記録するだけのときは、`--listen-only 秒数` を付けます。
  例：`run --listen-only 30`
- 作業フォルダが今のフォルダと違うときは、`--workdir フォルダ` を付けます。
- 設定ファイルを別の場所に置くときは、`--config ファイル` を付けます。
- 時間がかかることがあります。途中で止めずに、終わるまで待ってください。
  最長の目安は「コマンドの数 ×（command_timeout_seconds ＋ 10 秒）＋ listen_seconds ＋ 1 分」です。

### 2. 設定ファイルの場所を聞かれたとき、用意するよう頼まれたとき

```
python3 <このスキルのフォルダ>/scripts/capture.py config-path
```

- 設定ファイルがなければ、ひな形から作ります。
- 結果の `config` がファイルの場所、`missing` がまだ空の必須の項目です。
- ファイルを作れなかったときや読めないときは、`problems` に理由があります。

### 3. 設定を確かめるよう頼まれたとき

```
python3 <このスキルのフォルダ>/scripts/capture.py check
```

- 設定の書き方を確かめます。
- シリアルポートを開いて Enter を送り、機器が答えるかを見ます。
- ログインが要るときは、ログインできるかも確かめ、すぐにログアウトします。
- 機器のシェルでコマンドは実行しません。

## 結果の伝え方

スクリプトは、標準出力に JSON を1つ出します。
終わりのコードは次のとおりです。

- run：0 が成功、1 が作業の失敗、2 が設定の問題です。
- config-path：いつも 0 です。
- check：0 が問題なし、2 が問題ありです。

利用者には、次のように伝えます。

- `message` を、そのまま伝えます。
- ログのファイルの場所（`log`）を伝えます。
- run のとき
  - コマンドごとに、`command` と `output` を見せます。
  - `timed_out` が true なら、時間内に終わらず Ctrl-C で止めたと伝えます。
    それまでの出力は記録されていて、判断に使えます。終わらないプログラムを見るときは、command_timeout_seconds を見たい長さの秒数にします。
  - `truncated` が true なら、`output` は最後の 60 行だけです。全部はログにあります。
  - `listen` があれば、記録した出力（`listen` の `output`）を見せます。
  - `not_run` があれば、実行しなかったコマンドを伝えます。
- check のとき
  - `ok` と、`problems` の各文を伝えます。
  - 設定の要点（`summary`）を、表にして見せます。
- 設定に問題があるとき（`problems` があるとき）
  - `problems` の各文を、そのまま伝えます。
  - 設定ファイルの場所（`config`）を伝えます。
  - 設定ファイルは、利用者が直接直してよいと伝えます。
  - 各項目の意味は、項目のすぐ上のコメントにあると伝えます。

## 守ること

- 頼まれない限り、設定ファイルを書き換えません。
- つながらなかったときに、むやみにやり直しません。
  やり直さずに、原因を伝えて終えます。どうするかは、頼んだ側か利用者が決めます。
- パスワードを、画面やチャットに出しません。
