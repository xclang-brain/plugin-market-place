# 検証エージェント（triage-reviewer）

別のエージェントが作った Coverity の警告のトリアージの結果（1件、または1グループ）を、評価基準ごとに独立に確かめるエージェントです（3段階目）。

- 根拠のコードと警告経路を自分で読み直し、判定・確信度・推奨・修正案・逸脱コメント案が正しいかを確かめます。
- 答えは、合格・要確認・差し戻しのどれかと、基準ごとの指摘です。
- 書くのは、頼まれた確かめの結果のファイル（`review.json`）と、進み具合のファイルだけです。結果・差分・コードは直しません。
- 質問はしません。

## 使い方

ふつうは、統括エージェントが一括のトリアージの中で呼びます。自分で選ぶ必要はありません。

自分で確かめたいときは、`/agent` で `triage-reviewer · plugin` を選び、確かめる結果のファイルと差分と、調べたリポジトリを伝えて頼みます。

```text
<実行フォルダ>/items/20001/result.json と <実行フォルダ>/patches/20001-fix.patch を、このリポジトリのコードで確かめて
```

書くファイルを伝えなければ、確かめの結果はチャットに返ります。

## 使う部品

使うスキルは、[検証エージェントの定義](triage-reviewer.agent.md#使う部品)の「使う部品」の表にあります。取り出して使うときは、定義を `.github/agents/` に、表のスキルのフォルダを `.github/skills/<名前>/` にコピーします。

## Claude Code で使う

Claude Code 用の定義は、プラグインの `agents/triage-reviewer.md` です。使う部品の表と決まりは、Copilot CLI 用の定義と同じです。

- ふつうは、統括エージェントが一括のトリアージの中で呼びます。
- 自分で頼むときは、確かめる結果のファイルと差分と、調べたリポジトリを伝えて、「triage-reviewer エージェントで、<実行フォルダ>/items/20001/result.json と差分を確かめて」のように、名前を挙げて頼みます（`@` で選んでもかまいません）。`claude --agent coverity-triage-kit:triage-reviewer` で起動してもかまいません。
- 取り出して使うときは、定義 `agents/triage-reviewer.md` を `.claude/agents/`（自分だけで使うときは `~/.claude/agents/`）に、表のスキルのフォルダを `.claude/skills/<名前>/`（自分だけで使うときは `~/.claude/skills/<名前>/`）にコピーします。`/agents` に `triage-reviewer` が出れば完了です。

## うまくいかないとき

| 起きること | すること |
| --- | --- |
| `/agent` の一覧に `triage-reviewer` がない | プラグインが入っているか、取り出したときは `.github/agents/` に定義があるかを確かめる |
| スキルを使えないと言われる | `/skills list` で、表のスキルが読み込まれているかを確かめる |
| 「確かめるものが足りない」と返る | 結果のファイル・差分・調べたリポジトリの場所を、頼みの文に書く |
