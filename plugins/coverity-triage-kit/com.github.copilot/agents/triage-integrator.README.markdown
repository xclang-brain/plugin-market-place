# 統合エージェント（triage-integrator）

調べ終わったいくつかの Coverity の警告の結果から、同じ原因のものを見つけて、1つにまとめる計画を書くエージェントです（3段階目）。

- まとめるのは、原因が1つのものだけです。場所が近い・チェッカーが同じというだけでは、まとめません。
- 計画には、まとめる警告、理由、どの修正を使うか、まとめた見立てと逸脱コメントが入ります。
- 書くのは、頼まれた計画のファイル（`integration/plan.json`）と、進み具合のファイルだけです。コードと結果は直しません。
- 質問はしません。

## 使い方

ふつうは、統括エージェントが一括のトリアージの中で呼びます（設定で統合を使うと決めたとき）。自分で選ぶ必要はありません。

自分で頼みたいときは、`/agent` で `triage-integrator · plugin` を選び、まとめるか見たい結果のファイルを伝えて頼みます。

```text
<実行フォルダ>/items/20003/result.json と <実行フォルダ>/items/20004/result.json は同じ原因か確かめて、まとめる計画を見せて
```

書くファイルを伝えなければ、計画はチャットに返ります。

## 使う部品

使うスキルは、[統合エージェントの定義](triage-integrator.agent.md#使う部品)の「使う部品」の表にあります。取り出して使うときは、定義を `.github/agents/` に、表のスキルのフォルダを `.github/skills/<名前>/` にコピーします。

## うまくいかないとき

| 起きること | すること |
| --- | --- |
| `/agent` の一覧に `triage-integrator` がない | プラグインが入っているか、取り出したときは `.github/agents/` に定義があるかを確かめる |
| スキルを使えないと言われる | `/skills list` で、表のスキルが読み込まれているかを確かめる |
| まとめない計画が返る | 原因が1つだと言える根拠（同じマクロ、同じ関数の同じ欠陥など）が結果にないときは、まとめない。それが正しい答えのこともある |
