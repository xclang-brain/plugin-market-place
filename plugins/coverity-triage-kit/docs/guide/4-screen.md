# 4. 画面で確認して選ぶ

**所要時間**：5分　**前提**：[準備](../../README.md#準備最初の1回) が済んでいること

ブラウザーの画面で、処置の進捗と、CID ごとの修正コード・逸脱コメントを確認し、どちらを採用するかを選びます。1〜3段階目のどれで処置した結果も、同じ画面に表示されます。

## 1. 画面を開く

リポジトリのフォルダーで `copilot` を起動し、次のように入力します。2段階目や3段階目のエージェントを起動しているときは、別のターミナルを開いて `copilot` を起動します。Linux では、OK の後に Coverity に登録できるように、そのターミナルで先に、環境変数を設定する3行（[準備](../../README.md#準備最初の1回) の 2.）を実行します。

```text
画面を開いて
```

この PC のブラウザーで画面が開きます。開かないときは、チャットに表示された URL を開きます。2段階目や3段階目の処置を別のターミナルで実行している間に開くと、進捗が数秒ごとに更新されます。

| 画面の場所 | 表示されるもの |
| --- | --- |
| 上部 | 取得の条件と、処置を依頼するときに入力する文 |
| 進捗 | 「12 / 20 件、失敗 1 件」「処置中: 20004（10:32〜）」 |
| 一覧 | CID ごとの判定、確信度、修正コード（変更するファイル）、逸脱コメント、選択、状態 |
| 下部 | 選択ごとの件数と、「OK」を出すときに入力する文 |

## 2. CID ごとに選ぶ

一覧の CID（例: ▸ 20001）を選ぶと、概要、根拠（ファイル:行）、修正コードの差分、逸脱コメントが開きます。3段階目で処置した結果には、検証の指摘も表示されます。

1. 「選択」の列で、「修正を取り込む」「逸脱コメントを登録する」「何もしない」のどれかを選びます。最初は AI の推奨のとおりに選ばれています。ただし、確信度が低い CID や検証で要確認の CID などは「何もしない」になり、その下に理由が表示されます。選んだ内容は、すぐに保存されます。
2. 逸脱コメントを変えるときは、開いた欄で文面を編集し、「コメントを保存」を押します。1行、200文字以内で、先頭の「誤検知。」などの語はそのまま残します。「元に戻す」を押すと、AI が作成した文面に戻ります。

3段階目の実行中は、「検証」の列に結果（合格・要確認・未検証）が表示された CID から選びます。検証の前に選んだ内容と編集したコメントは、検証が終わると取り消されます。

## 3. チャットで OK を出す

選び終えたら、チャットに次のように入力します。

```text
画面で選んだ内容で進めて
```

画面で選んだ内容の一覧がチャットに表示されます。「OK」と答えると、修正の取り込みと逸脱コメントの登録が行われます（[1段階目の手順3](1-skill.md#3-一覧を確認してok-を出す) と同じです）。

## 画面を閉じる

ブラウザーのタブを閉じ、チャットに「画面を閉じて」と入力します。入力しなくても、タブを閉じてから30分たつと、画面のサーバーは自動で終了します。
