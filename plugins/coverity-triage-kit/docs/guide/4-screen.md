# ステップ4：画面で進み具合と結果を確認する

**所要時間**：10分　**必要なもの**：[ステップ3](3-batch.md) を終えていること（一括トリアージを1回実行していること）

このステップでは、ブラウザーの画面で、一括トリアージの進み具合と結果を確認します。あなたが行うのは、警告ごとに「修正」か「逸脱」かを選び、必要なら逸脱コメントを直すことです。

## 1. 画面を開く

リポジトリで Copilot CLI を起動し、次のコマンドを入力します。

```text
/coverity-triage-kit:coverity-gui
```

この PC のブラウザーで画面が開きます。開かないときは、チャットに表示された URL をブラウザーで開いてください。

## 2. 3つのタブを切り替える

| タブ | 表示される内容 |
| --- | --- |
| 監視 | 実行中の一括トリアージの進み具合。エージェントごとの状態、警告ごとの状態と経過時間、エラーが、2秒ごとに更新されます |
| 結果 | 実行の一覧と、警告の一覧（確信度の低い順）。警告ごとに、詳細レポート、修正の差分、修正後のファイルを開けます |
| 設定 | 接続先、条件ファイル、オプションなどの設定。保存の前に、変更する項目が一覧で表示されます |

## 3. 警告ごとに選び、逸脱コメントを直す

「結果」タブで実行を選ぶと、警告の一覧が表示されます。

1. 一覧の「承認」の列で、警告ごとに「修正」「逸脱」「却下」「反映しない」のどれかを選びます。最初は AI の推奨が入っています。選んだ内容は、すぐに保存されます。
2. 行を選ぶと、詳細が開きます。左に詳細レポート、右に承認と逸脱の内容（Classification、Action、Severity、逸脱コメント）が表示されます。
3. 逸脱コメントを直して「保存」を押します。詳細で直した内容は、「保存」を押したときに保存されます。「AI の案に戻す」を押すと、元の案に戻ります。

## 4. 反映を依頼する

選び終えたら、チャットで `/coverity-triage-kit:coverity-apply` と入力して、反映を依頼します。反映する内容が件数と ID で表示され、「はい」と答えると反映されます（[ステップ3の「反映する」](3-batch.md#3-反映する) と同じ流れです）。

## ここまでで分かったこと

- 4段階目は、進み具合の確認、警告ごとの選択、設定の変更を、1つの画面で行う使い方です。
- 画面で行うのは確認と選択です。Coverity とリポジトリへの反映は、チャットで依頼したときに行われます。

これでチュートリアルは終わりです。日常の運用で必要になる情報は、[README の文書一覧](../../README.md#文書) から探せます。

---

### 補足

- **実行中に開く**：一括トリアージの実行中は、「監視」タブで進み具合が分かります。10分動きがない警告には「⚠ 停止?」と表示されます。
- **画面を終了する**：画面の右上のメニューの「サーバを止める…」を押すか、チャットで「画面のサーバを止めて」と依頼します。
