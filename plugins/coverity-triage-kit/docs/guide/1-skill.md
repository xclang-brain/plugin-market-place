# 1. 1件ずつ処置する

**所要時間**：10分　**前提**：[準備](../../README.md#準備最初の1回) が済んでいること

警告を取得し、CID を1件指定して、修正コードと逸脱コメントを作成します。出力の形と、最後の「OK」までの流れが分かります。

## 1. 警告を取得する

リポジトリのフォルダーで `copilot` を起動し、次のように入力します。

```text
条件に合う警告を取得して
```

設定ファイルの条件（最初は「未分類の警告を20件まで」）で、Coverity から警告を取得します。途中で Copilot CLI がツールやコマンドの許可を確認したときは、「このセッションでは許可」を選びます。

```text
条件に合う警告を 6 件取得しました
20001  RESOURCE_LEAK  src/reader.c:20  High
20002  FORWARD_NULL   src/reader.c:15  Medium
…
```

## 2. CID を1件、処置する

```text
CID 20002 を処置して
```

プラグインが、警告の経路を呼び出し元までコードで確認し、次の2つを作成します。

```text
CID 20002（FORWARD_NULL、src/reader.c:15）
判定：誤検知（確信度：高）　推奨：逸脱コメントを登録する
根拠：
- src/reader.c:32 read_config() は、path が NULL なら open_and_read() を呼び出す前に返る
- src/reader.c:36 open_and_read() の呼び出し元は、ここだけ

修正コード：open_and_read() の先頭に NULL チェックを追加する（現在の呼び出し元では通らない分岐）
  （差分）

逸脱コメント（78文字）：
誤検知。唯一の呼び出し元 read_config()（src/reader.c:32〜36）が path の NULL を除外してから渡しており、NULL を参照することはない。

続けるときは「次を処置して」、修正の取り込みと逸脱コメントの登録に進むときは「まとめを見せて」と入力してください
```

修正コードは、リポジトリの外の作業用コピーで作成されます。この時点では、リポジトリも Coverity も変わっていません。

続けて処置するときは、「次を処置して」または「CID 20001 を処置して」と入力します。結果を直したいときは、「CID 20002 を処置して。呼び出し元は admin.c にもある」のように、指摘を添えてもう一度依頼します。

## 3. 一覧を確認して、OK を出す

```text
まとめを見せて
```

取得した CID の一覧が表示されます。処置済みの CID には、修正コード、逸脱コメント、選択（最初は推奨のとおり）が並びます。まだ処置していない CID は、「未処置」と表示されます。

| CID | 判定 | 確信度 | 修正コード | 逸脱コメント | 選択 | 備考 |
| --- | --- | --- | --- | --- | --- | --- |
| 20001 | 本物のバグ | 高 | src/reader.c | 本物のバグ。…（Bug／Ignore／Major） | 修正を取り込む | |
| 20002 | 誤検知 | 高 | src/reader.c | 誤検知。…（False Positive／Ignore／Unspecified） | 逸脱コメントを登録する | |
| 20003 | - | - | - | - | - | 未処置 |

```text
この内容で、修正の取り込み（1 件）、逸脱コメントの登録（1 件）を行います。…よろしければ「OK」と入力してください。
```

- そのまま進めるときは、「OK」と答えます。
- 選択を変えるときは、「20002 は修正、ほかは OK」「20001 は何もしない」のように答えます。

「OK」の後、プラグインが修正の取り込みと逸脱コメントの登録を行います。Coverity に書き込む直前には、Copilot CLI が許可を確認します。

```text
修正 1 件をブランチ coverity-fix/20261110-153000 にコミットして push しました。続けて、逸脱コメント 1 件と、取り込んだ修正 1 件を Coverity に登録します
プルリクエスト：https://github.com/…/compare/main...coverity-fix/20261110-153000?expand=1
```

git では、表示された URL を開いてプルリクエストを作成します。svn では、作業コピーに差分が適用されるので、内容を確認してコミットします。
