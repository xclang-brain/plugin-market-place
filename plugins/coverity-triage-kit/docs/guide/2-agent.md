# 2. すべての警告を任せる

**所要時間**：操作は5分（処置の時間は、警告1件あたり数分）　**前提**：[準備](../../README.md#準備最初の1回) が済んでいること

1つのエージェントが、条件に合う警告をすべて取得し、1件ずつ最後まで処置します。処置の間、質問はありません。

## 1. エージェントを起動して依頼する

リポジトリのフォルダーで、エージェントを指定して Copilot CLI を起動します。

```shell
copilot --agent coverity-triage-kit:triage-worker
```

次のように入力します。

```text
条件に合う警告をすべて処置して
```

エージェントが警告を取得し、CID ごとに修正コードと逸脱コメントを作成します。最初に Copilot CLI がツールやコマンドの許可を確認したときは、「このセッションでは許可」を選びます。

```text
条件に合う警告は 137 件あります。設定の上限（20 件）まで取得しました
```

## 2. 一覧を確認して、OK を出す

すべての処置が終わると、一覧が1つ表示されます（[1段階目](1-skill.md#3-一覧を確認してok-を出す) と同じ形です）。

| CID | 判定 | 確信度 | 修正コード | 逸脱コメント | 選択 | 備考 |
| --- | --- | --- | --- | --- | --- | --- |
| 20001 | 本物のバグ | 高 | src/reader.c | 本物のバグ。… | 修正を取り込む | |
| 20003 | 判定不能 | 低 | src/reader.c | 本物のバグ。… | 何もしない | 確信度が低いため |

```text
CID ごとの修正コードと根拠は C:/work/coverity-triage-out/20261110-153000/summary.md にあります
この内容で、修正の取り込み（12 件。ブランチ coverity-fix/20261110-153000 にコミットして origin に push）、逸脱コメントの登録（5 件）を行います。…よろしければ「OK」と入力してください。
```

差分と根拠は、`summary.md` で確認できます。「OK」と答えると、修正の取り込みと逸脱コメントの登録が行われます。選択を変えるときは、「20003 は修正、ほかは OK」のように答えます。結果そのものを直したいときは、エージェントの処置が終わってから、エージェントを指定せずに `copilot` を起動し、「CID 20003 を処置して。呼び出し元は admin.c にもある」のように指摘を添えて依頼して、「まとめを見せて」と入力します。

## 3. 続きの警告を処置する

「OK」の後に同じ依頼をもう一度入力すると、条件に合う警告を取得し直して処置します。取り込みや登録が済んだ CID は Coverity で分類済みになり、その分だけ新しい警告が入ります。「何もしない」の CID は未分類のままなので、次の取得にも入り、最初から処置されます。新しい警告に進むには、一覧で「20003 は逸脱、ほかは OK」のように、修正か逸脱を選びます。1回の件数を増やすときは、[設定](settings.md) の `limit` を変更します。

## 中断したとき

同じ手順で起動して、同じ依頼をもう一度入力します。「前回の続きから進めます（残り 7 件）」と表示され、続きから進みます。処置が終わっていて「OK」を出していないときは、一覧の表示から再開します。最初から取得し直すときは、「取得し直して」と入力します。

## 席を離れて実行する

許可の確認で止まらないように、必要な許可を指定して起動します。`<結果フォルダーの場所>` は、設定の `output_dir` のフォルダーです（最初は、リポジトリと同じ階層の `coverity-triage-out`）。

```shell
copilot --agent coverity-triage-kit:triage-worker --add-dir "<結果フォルダーの場所>" --allow-tool 'shell(uv:*)' --allow-tool write --allow-tool 'coverity-connect(coverity_search_issues)' --allow-tool 'coverity-connect(coverity_get_issue_details)'
```

Coverity に書き込むツールは、この指定に含めていません。書き込みの前には、必ず許可の確認が表示されます。
