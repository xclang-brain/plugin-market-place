# 画面

ブラウザーの画面に、処置の進捗と、CID ごとの修正コード・逸脱コメントを表示します。利用者は、画面で CID ごとに「修正を取り込む」「逸脱コメントを登録する」「何もしない」のいずれかを選択し、必要に応じて逸脱コメントを編集します。選択した内容は、結果フォルダーの `decisions.json` に保存されます。

`<リポジトリ>` は、git または svn の作業ツリーの最上位フォルダーです。どちらのコマンドも JSON を1つ返します。`ok` が `false` のときは、`error` の文を利用者に伝えて終了します。

## 画面を開く（「画面を開いて」）

```
uv run --native-tls --quiet "<このスキルのフォルダー>/scripts/gui.py" open --repo "<リポジトリ>"
```

1. `message` を利用者に伝え、その下に `url` を省略せずに示します。
2. 続けて、次の文を伝えます。「選択が終わったら、チャットに「画面で選んだ内容で進めて」と入力します。一覧が表示されるので、「OK」と答えると、修正の取り込みと逸脱コメントの登録を行います。」

画面は、このコマンドの終了後も表示を続け、新しい結果フォルダーができると、その内容に切り替わります。もう一度「画面を開いて」と依頼されたときは、同じコマンドを実行します（起動済みの画面の URL が返ります）。

## 画面を閉じる（「画面を閉じて」）

```
uv run --native-tls --quiet "<このスキルのフォルダー>/scripts/gui.py" stop --repo "<リポジトリ>"
```

`message` を利用者に伝えます。
