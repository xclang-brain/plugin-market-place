Coverity の警告の処置

処置は、Copilot CLI のチャットで依頼します。

  • 1件ずつ: 「条件に合う警告を取得して」「CID 20002 を処置して」と入力します
  • すべて（エージェント1つ）: copilot --agent coverity-triage-kit:triage-worker を起動して、「条件に合う警告をすべて処置して」と入力します
  • すべて（マルチエージェント）: copilot --agent coverity-triage-kit:triage-orchestrator を起動して、「条件に合う警告をすべて処置して」と入力します

進捗

CID ごとの修正コードと逸脱コメント

CID を選択すると、根拠と修正コードの差分を表示します。採用する方を「選択」の列で選びます。

選択が終わったら、チャットに「画面で選んだ内容で進めて」と入力します。一覧が表示されるので、「OK」と答えると、修正の取り込みと、逸脱コメントと保留の登録を行います。
