The proposed deviation comment states the disabled fact without any condition about the future. It has no condition, caveat, guess, request or instruction to the reader: none of ただし, 但し, 場合に限, 場合のみ, に限り, 場合は, 前提, に依存, 間だけ, 見直, おそらく, と思われ, ください, を推奨, すべき, and no sentence that tells the reader what to do (for example one ending in 〜こと。). A stated precondition such as 「この判断の前提: …」 fails even if none of these words is used. For example 「条件: この逸脱は legacy_export が無効である間だけ有効」 or 「有効にする前に直すこと」 fails.
