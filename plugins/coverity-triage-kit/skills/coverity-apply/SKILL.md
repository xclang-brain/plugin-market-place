# 修正の取り込みと逸脱コメントの登録

処置済みの CID の一覧を示し、利用者が OK と答えた後に、CID ごとの選択（修正を取り込む／逸脱コメントを登録する／何もしない）のとおりに、修正をリポジトリに取り込み、逸脱コメントを Coverity に登録します。利用者のリポジトリと Coverity が変わるのは、OK の後だけです。

## 1. 一覧を示して、1回だけ質問する

```
uv run --native-tls --quiet "<このスキルのフォルダー>/scripts/apply.py" plan --repo "<リポジトリ>"
```

`<リポジトリ>` は、git または svn の作業ツリーの最上位フォルダーです。コマンドは JSON を1つ返します。

- 最初は、推奨の選択が入っています（確信度が低い CID などは「何もしない」）。画面で選んだ内容（`decisions.json`）があれば、それが入ります。以前にチャットで指定して OK と答えた選択も、そのまま入ります（備考は「チャットで指定」）。
- 利用者が CID の選択を変更したときは、変更ごとに `--set <CID>=<選択>` を付けます。修正は `fix`、逸脱は `deviation`、何もしないは `none` です（「20003 は逸脱、20007 は何もしない」は `--set 20003=deviation --set 20007=none`）。`plan` を実行するたびに、この会話で指定された変更をすべて付けます。
- `table` をそのまま表示します。`summary_file` が `null` でないときは、「CID ごとの修正コードと根拠は <summary_file> にあります」と伝えます。
- `question` を1回だけ質問して、回答を待ちます。`question` がないときは、`message` を伝えて終了します。
- `ok` が `false` のときは、`error`（`problems` があれば、その内容も）を利用者に伝えます。`problems` を自分で訂正できるとき（統合先の CID を指定する、など）は、`--set` を訂正して、もう一度実行します。
- 利用者に質問できないとき（対話のない実行など）は、`table` を表示して終了します。取り込みと登録は、利用者が OK と答えた後に行います。

## 2. 回答のとおりに実行する

| 回答 | 行うこと |
| --- | --- |
| 「OK」 | `next` のコマンド（`apply`）を実行します |
| 変更と OK（「20003 は逸脱、ほかは OK」） | `--set` を付けて `plan` を実行します。OK は得ているので、そのまま `next` のコマンド（`apply`）を実行します |
| 変更だけ（「20003 は逸脱にして」） | `--set` を付けて `plan` を実行し、`table` を表示して、もう一度質問します |

`apply` の応答の `changed` が `true` のときは、一覧を表示した後に、結果または選択が変更されています。`next` のコマンド（`plan`）を実行し、`table` を表示して、もう一度質問します。

## 3. Coverity に登録して、結果を報告する

`apply` の応答の `call` にあるツール（`coverity_update_triage`）を、`arguments` のとおりに呼び出します（`call` が空のときは、登録するものはありません）。呼び出すときに、Copilot CLI が許可の確認を表示します。ツールの応答の `done` が `false` のときは、同じ引数でもう一度呼び出します。続けて、次を報告します。

- `message`
- git：ブランチ名（`git.branch`）と、プルリクエストのタイトル（`git.pr.title`）、作成用の URL（`git.pr.compare_url`。URL がないときは、本文 `git.pr.body`）。svn：変更したファイル（`svn.files`）
- Coverity に登録した CID（ツールの応答の `written`）
- 取り込めなかった修正（`fixes.failed`）と、登録できなかった CID（ツールの応答の `failed`）。それぞれ理由を添えます
- `git.push_error` があるときは、その内容。「修正を取り込んで」と入力すると、もう一度 push します
- ツールの呼び出しが許可されなかったとき、またはエラーになったときは、その内容。「修正を取り込んで」と入力すると、残りを登録します
