# 変更履歴

利用者から見て変わったことを書きます。新しいバージョンが上です。

## 0.3.0（2026-11-10）

覚えることを減らすために、機能を絞りました。

- 画面を1つにしました。`/coverity-triage-kit:coverity-gui` で開く画面で、進み具合の確認、警告ごとの選択、設定の変更を行います。Copilot CLI のエクステンションとして動いていた Web管理画面と、そこからの Issue の起票は削除しました。
- ヘルプ（`/coverity-help`）と自己診断（`/coverity-selftest`）のスキルを削除しました。設定・認証情報・接続は、`/coverity-triage-kit:coverity-setup` で確認できます。
- 運用ガイドを削除しました。無人で実行するときの許可の指定は、チュートリアルのステップ3にあります。
- 文書のコマンドを、プラグイン名を付けた形（`/coverity-triage-kit:<スキル名>`）に直しました。
- プラグインのファイル数は、905 から 655 に減りました。

## 0.2.0（2026-11-09）

- エージェントの定義を作り直しました。作業エージェントが作業中のファイルを修正するのは、利用者が差分に同意したときだけです。
- 一括トリアージで、途中の実行があるときに「前回の続きから」と依頼すると、確認の質問なしで再開します。

## 0.1.0（2026-11-08）

最初のバージョンです。スキルと MCP サーバー、作業エージェント、一括トリアージ、画面の4つの段階で使えるようにしました。
