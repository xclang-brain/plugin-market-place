# 変更履歴

利用者から見て変わったことを書きます。新しいバージョンが上です。

## 0.3.0（2026-11-10）

行うことを「条件に合う警告を取得し、CID ごとに修正コードと逸脱コメントを出力する」の1つに絞り、全体を作り直しました。以前のバージョンの設定ファイルと結果フォルダーは、そのままでは使えません。`.coverity-triage/config.yaml` を削除してから、`/coverity-triage-kit:coverity-setup <URL> <ストリーム>` と入力して、設定ファイルを作成し直してください（`.coverity-triage/knowledge.md` は、そのまま使えます）。

- 2段階目のエージェント（`triage-worker`）が、条件に合う警告を設定の上限まで取得し、最後まで処置するようになりました。
- 3段階目は、エージェント `triage-orchestrator` を起動して依頼する形になりました。並列の処置、同じ原因の CID の統合、別のエージェントによる検証を、常に行います。
- どの段階でも、最後に一覧が1つ表示されます。「OK」と答えると、プラグインが修正をリポジトリに取り込み、逸脱コメントを Coverity に登録します。取り込んだ修正も、Coverity に「Bug／Fix Required」として登録します。
- 修正も逸脱コメントも採用しない CID は、「保留にする」を選びます（確信度が低い CID などは、最初からこの選択です）。OK の後に Coverity に「Pending」と理由を登録し、次の取得からは除きます。保留にした警告は、Coverity で確認するか、設定の `classification` に `Pending` を加えて取得し直します。
- git では、チェックアウトしているブランチの最新のコードで処置し、そのブランチへのプルリクエストを用意します。ブランチを切り替えた後の依頼は、新しい結果フォルダーで取得し直します。
- 準備は3ステップになりました（インストール、認証情報の設定、URL とストリームの入力）。設定は1ファイル、13項目です。
- 画面は、進捗の確認と、CID ごとの選択に絞りました。「画面を開いて」と入力すると開きます。
- 次の機能を削除しました：Copilot CLI のエクステンションの画面、Issue の起票、ヘルプと自己診断のスキル、条件ファイル、画面からの設定の編集、HTML のレポート。
